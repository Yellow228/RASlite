## 一、必须下载（软件 + 示例算例）

### 1. HEC-RAS 软件下载页（总入口）
- 官网：https://www.hec.usace.army.mil/software/hec-ras/
- 下载页（含各版本安装包）：**https://www.hec.usace.army.mil/software/hec-ras/download.aspx**
  - 当前版本 HEC-RAS 7.0.1（Windows，171 MB）
  - **该页面上有 "HEC-RAS 7.0 Example Projects" 独立压缩包——包含全部官方示例工程**，这是验证你程序的关键数据，单独下载即可，不装软件也能解压看
  - 装软件后，安装目录里同样自带 Example Projects 文件夹

### 2. 官方示例算例的获取方式（二选一）
- 方式 A：从上面下载页单独下 Example Projects 压缩包（推荐）
- 方式 B：安装 HEC-RAS 后，到安装目录的 Example Projects 文件夹取
- 重点算例：BaldEagleCrk（天然河道水面线）、BeaverCreek、Muncie 等；验证时优先选无建筑物的河段算例

## 四、需自行购买/借阅（无官方免费渠道）

### 9. Chow《Open Channel Hydraulics》(1959)
- 标准步进法、比能函数、水面线分类的源头教材，临界水深求根的数值处理参考其中比能函数章节
- **不要从网上找盗版**；图书馆借阅或 McGraw-Hill / 电商平台购买影印版均可。若暂时不买，第 8 条的百科条目能覆盖标准步进法的最小知识量

### 10. 中文教材任选其一（比能/临界流章节）
- 《水力学》（吴持恭，高等教育出版社）上册，或
- 《工程水力学》等任一含"水面线定性分析+比能函数"章节的教材
