# 一维水面线程序开发：准备清单与可行性评估

> 日期：2026-10-15
> 目标：编写一维水面线推算程序，计算能力对标 HEC-RAS 一维模块
> 配套文档：《HEC-RAS一维水面线计算原理资料汇编.md》

---

## 0. 先给结论

1. **可行，但"结果相同"要改成"误差可控"**。恒定流能量方程 + 标准步进法本身是公开、成熟的算法，自己实现不难；难在把 HEC-RAS 的工程实现细节对齐（断面几何处理、收敛策略、边界情况）。建议验收目标定为：**与 HEC-RAS 对同一算例的水面线逐断面误差 ≤ 1 cm**（工程上完全够用），而不是逐位一致。
2. **必须先定技术路线**（见第 1 节），这决定工作量差 3～5 倍。
3. **当前资料缺"实现层"内容**，需要补 4 类材料（见第 3 节）。

---

## 1. 路线选择（先定，再动手）

| 路线 | 控制方程 | 难度 | 对标对象 | 依赖 |
|------|----------|------|----------|------|
| A. 恒定渐变流 | 能量方程 + 标准步进法 | ★★ | HEC-RAS Steady Flow (RAS Mapper 之外的 1D 恒定流) | 已有资料基本够 |
| B. 非恒定流 | 圣维南方程组（连续+动量），Preissmann/FVM 离散 | ★★★★ | HEC-RAS Unsteady Flow / 动力波 | 需另补数值离散教材 |

**建议**：先做 A。理由：
- A 是水面线推算的主体，也是 B 的几何/水力要素计算基础（断面属性模块 100% 复用）；
- A 有大量解析解和官方算例可验证，B 的验证要靠过程线对比，门槛高；
- 国内设计院的"水面线计算"需求 90% 落在 A。

若你的"水动力方程"确实指非恒定流（洪水演进、溃坝），A 做完后 B 的动量方程部分可以顺势补。

## 2. 程序需要实现的组件清单（路线 A）

### 2.1 几何模块（工作量最大、最容易埋 bug）
- [ ] 横断面数据结构：坐标点序列 (x, z)、左右滩分界、分区 n 值突变点、左右滩/主槽分别的下游间距
- [ ] 给定水位 WSE → 计算 A（过水面积）、P（湿周）、T（水面宽）、R=A/P、各分区 A_i / K_i
  - 注意：要处理封闭断面（管流）、局部高点（crew 不到位会导致 K 突跳）
- [ ] 输水能力 K 分区求和（默认按 n 值突变点划分；可选 HEC-2 逐点法）
- [ ] 无效流动区（Ineffective Flow Areas）：只计面积不计输水/动量——桥背水侧必需
- [ ] 断面内插（可选，河网加密用）

### 2.2 水力学核心
- [ ] 临界水深：比能 E(y)=A·ȳ+A·αV²/2g 求最小值 → 数值求根（建议 Brent 法 + 拐点初值处理；临界流附近 E-y 曲线可能无解或多解）
- [ ] 正常水深：曼宁公式求根
- [ ] 标准步进迭代（7 步流程 + 容差 0.003 m + 最大迭代次数）
  - 试值策略：第 1 次 = 上一断面水深投影；第 2 次 = 假定 + 0.70×误差；之后割线法
  - **收敛失败处理**：迭代不收敛时 HEC-RAS 默认取临界水深并报警——这个行为必须复刻，否则混合流算例对不上
- [ ] 摩阻坡度 S̄f 4 种算法（默认平均输水能力法），按水面线类型自动选型可后做
- [ ] 亚临界（自下而上）/ 超临界（自上而下）双向推算
- [ ] 混合流：比力 SF = Q²β/(gA) + A·Ȳ，两轮计算 + 比力比较 + 水跃定位
- [ ] 边界条件 4 种：已知水位 / 临界水深 / 正常水深 / 水位流量关系

### 2.3 河网与工程（可分期）
- [ ] 支流汇合（junction）：默认能量平衡，可选动量平衡
- [ ] 桥/涵/堰：这是 HEC-RAS 独立的大模块（能量法/动量法/Yarnell/压力流），**第一版建议不做**，先保证天然河道段对齐

### 2.4 输出与对比
- [ ] 逐断面输出：WSE、临界水深、流速水头、EG（能量线高程）、Fr、K、α、流速——字段对齐 HEC-RAS 的 Detailed Output，方便逐项核对

## 3. 还需要准备的资料（按优先级）

### ① 官方示例算例（验证用，最重要）
- HEC-RAS 安装目录自带 **Example Projects**（或官网 Confluence 下载），里面有一维恒定流标准算例
- 备选：HEC 官方培训教材《Applying HEC-RAS》附习题数据
- 用途：几何/流量/糙率输入喂给自己的程序，输出与 HEC-RAS 逐断面对比

### ② 官方手册"实现层"章节（现有资料只覆盖了第 2 章前半）
- Reference Manual 第 2 章剩余部分：**临界水深判定细节、收敛失败处理、混合流计算选项**
- Reference Manual 第 3 章 **Basic Data Requirements**：无效流动区、障碍物、n 值取值、C 系数取值表
- Users Manual 中 Steady Flow 计算选项（容差设置、S̄f 方法切换入口）
- 获取：上面资料汇编里第 1、2 条链接（HEC 官网 PDF），**不需要额外下载渠道，直接官网取**

### ③ 数值方法底稿（防踩坑）
- 断面几何插值在水位跨越滩地时的不连续问题
- 临界水深求根的多解/无解处理（建议参考：Chow《Open Channel Hydraulics》或任意《水力学》教材的比能函数章节）
- 标准步进法不收敛的常见原因清单（断面间距过大、n 值突变、断面突变）——HEC 官方 Confluence "Steady Flow Computation Issues" 页面有系统总结

### ④ 对比工具链
- HEC-RAS 结果导出：Profile Output Table → CSV/剪贴板，写个小脚本对齐断面号做误差统计
- （可选）解析解算例：宽矩形渠道、单一糙率、无建筑物 → 手算/文献解核对，隔离几何模块的 bug

## 4. 验收与验证策略（分四级，逐级过）

| 级别 | 算例 | 验证什么 | 通过标准 |
|------|------|----------|----------|
| L1 | 单一棱柱形矩形渠道 + 解析解 | 能量方程+迭代本身 | 与解析解差 < 1 mm |
| L2 | 复式断面（滩槽+分区 n）无建筑物 | 几何模块、K、α | 与 HEC-RAS 差 ≤ 1 cm |
| L3 | 官方示例：天然河道 + 亚临界/超临界/混合流 | 边界条件、混合流、临界水深默认行为 | 逐断面 WSE 误差 ≤ 1 cm |
| L4 | 汇流、河网 | junction 处理 | ≤ 2 cm（junction 本身离散性大） |

每级不过不进下一级——几何模块的 bug 混进混合流算例里会查到怀疑人生。

## 5. 隐性风险（提前说）

1. **HEC-RAS 内部未公开细节**：断面几何内插的具体方式、迭代内部细节只能靠黑盒对比反推。个别算例卡在 1～2 cm 对不上属正常，先保证趋势和量级。
2. **断面数据的"脏"问题**：真实地形数据里常有封闭凹陷、竖直壁、重复点，几何函数要先做数据清洗，否则 K 值算出鬼数。
3. **单位制**：官方手册公式混用英制（1.486 系数）与公制，代码统一公制并集中写单位换算，别散在公式里。
4. **不要一上来做 GUI**：先做纯计算核心 + CSV 输入输出，验证通过后再考虑界面或接入 GIS。

---

## 6. 建议开发顺序

1. 几何模块（断面属性计算）+ 单元测试
2. 临界水深 / 正常水深求根 + 测试
3. 标准步进法主循环（亚临界）+ L1/L2 验证
4. 边界条件 4 种 + 超临界
5. 混合流（比力判别）+ L3 验证
6. 河网/junction + L4
7. （二期）建筑物：桥、涵、堰
